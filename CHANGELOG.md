## 0.1.1-beta.2 — 2026-11-16

### Added

- **Route latency reports p50 and p95 from per-window histograms, with the previous period, and slow routes are judged on p95** (`routeLatency`, `routeTrend`, `histogramQuantile`, `mergeHistograms`, `LATENCY_BUCKETS_MS`, `RouteLatencyRow`, `PerformanceThresholds`, `performanceDrizzleSchema`, `routeLatencyWindows`)
  Every route window now keeps a latency histogram (`latency_buckets`: 10ms to 10s, log-spaced, then one for anything slower), merged bucket by bucket when two processes flush the same window. `routeLatency` reports `p50Ms`, `p95Ms` and the previous period (`previous: { calls, p95Ms }`); `routeTrend` adds `p95Ms` per hour; slow-route problems are judged on p95 (`slowRouteP95Ms`, default 1000ms), falling back to the mean only for windows written before the buckets. `histogramQuantile`, `mergeHistograms` and `LATENCY_BUCKETS_MS` are exported. Applications that own the schema add `latency_buckets integer[] NOT NULL DEFAULT '{}'` to `route_latency_windows`.
